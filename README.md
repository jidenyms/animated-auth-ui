# Nova — Creative Animated Login

A cinematic, responsive authentication interface designed to turn a routine login flow into a memorable product moment. Nova combines a space-inspired visual system with polished UI interactions and accessible form behaviour.

## Features

- Animated orbital artwork created entirely with CSS
- Smooth login and account-creation transitions
- Responsive split-screen design
- Client-side form validation
- Password visibility control
- Loading and success states
- Theme switcher
- Social sign-in preview states
- Reduced-motion accessibility support
- Mobile-first responsive layout

## Built with

- Semantic HTML5
- Modern CSS (Grid, custom properties, gradients, animations)
- Vanilla JavaScript

## Run locally

No dependencies or build tools are required.

```bash
git clone https://github.com/jidenyms/animated-auth-ui.git
cd animated-auth-ui
```

Open `index.html` in your browser or use a local development server such as VS Code Live Server.

## Important

This project is a frontend interaction demo. It does not submit or store credentials. Authentication buttons are ready to be connected to a secure backend or OAuth provider.
